## Overview  
Welcome to the HR Data Analysis Project — where raw employee data transforms into meaningful insights. This project dives into the pulse of your workforce by analyzing employee tenure, performance ratings, and other key HR metrics to help managers make smarter, data-driven decisions.

## Purpose  
The goal? Unlock hidden patterns in employee retention, evaluate performance trends, and highlight areas for improvement in talent management. Because a company that knows its people, knows its future.

## Features  
- Data cleaning to ensure no sneaky null values sabotage the analysis  
- Performance rating trends tracked over time by review dates  
- Insights on employee tenure and impact on performance  
- Visualizations to simplify complex HR metrics  
- SQL and Python-powered data wrangling and reporting
- Tableau & Poer BI For visualization
